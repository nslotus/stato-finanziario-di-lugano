# Archived sources

The documents the figures were read from, kept exactly as downloaded so that every figure can be checked against the
document it cites. [`MANIFEST.json`](MANIFEST.json) records each file's original URL, publisher, retrieval time, size and
SHA-256; [`../SOURCES.md`](../SOURCES.md) lists them. `npm run verify` fails if any file differs from its fingerprint.

**Rights.** The documents are published by public authorities (the City of Lugano, the Canton of Ticino, the Swiss
Confederation and their offices) and by other bodies (among them AIL SA, the Fondazione Conservatorio della Svizzera
italiana, LAC Lugano Arte e Cultura, USI, SUPSI and SBB). They remain under the terms of their publishers and are
reproduced here unchanged, for the sole purpose of making the figures verifiable. They are not covered by this project's
licences. For the current version of a document, follow its original link.

If you publish one of these documents and would rather it were not archived here, please open an issue. The figures will
then cite the original link and fingerprint only.

Some original links no longer return the same file (a web page that has been updated, a document that has moved). The
archived copy is the one the figures were read from.
